# 折纸折痕图工作室

在浏览器里设计折痕图、自动校验折纸定理、判定整张图能否平折，并播放 60 帧折叠动画的 TypeScript + WebGL2 应用。零运行时依赖。

## 功能对照需求

| 需求 | 实现 |
| --- | --- |
| 川崎定理误差 ≤ 0.1° | `src/core/theorems.ts`，按扇形角隔角和计算偏差，超差顶点标红并给出具体偏差度数 |
| 山线/谷线分开绘制 | 山线红色虚线、谷线蓝色点线、边界黑实线（`src/gl/renderer.ts`、`src/core/svgExport.ts`） |
| 网格与角度吸附 | `src/ui/editor.ts`，网格间距、角度步长可调，画错的顶点点击即可定位 |
| 顶点定理诊断 + 标红 | 内部顶点校验川崎+前川；错误面板说明违反了哪条定理、偏差多少 |
| 单顶点都对但整图不平 | `src/core/foldability.ts`：局部最小角检查 + 全局层序偏序有向图环检测，报告互相卡住的面 |
| 层叠顺序/每层是哪块纸 | 无环时按弱连通分量拓扑排序，给出每个面的层号 |
| 作品/版本本地存储 | `src/core/storage.ts`，localStorage 多作品多版本，支持 JSON 导入导出 |
| 折痕图导出 SVG | 折痕图、层序着色图、折法步骤图（一步一张）均可下载 |
| TypeScript + WebGL2 | 手写 GLSL 与缓冲管理，2D 编辑画布 + 3D 折叠动画双模式 |
| 200 顶点 60 帧 | 225 顶点、196 面全套分析 + 60 帧约 0.22 秒 |
| 经典图案生成 | 三浦、吉野、水雷、四方扭转镶嵌 + 水雷/鹤/蛙三种底型 |

## 定理说明

- **川崎定理（平折必要条件）**：内部顶点周围隔位扇形角之和相等，即奇数位扇形角和 = 偶数位扇形角和 = 180°。
- **前川定理**：内部顶点山线数与谷线数之差为 2（4 射线 3:1、8 射线 5:3、16 射线 9:7）。
- **全局平折**：单顶点定理都满足只是必要条件；本工具进一步把每个顶点的面堆叠关系汇成全局有向图，若出现有向环则这些面在折叠时互相卡住、无法平折，并指出具体面与顶点。

## 已知边界

- 层序分析采用单顶点最小角归并（树算法）构造局部约束；跨顶点方向约定冲突时按多数一致原则松弛，并在报告中注明松弛条数。
- 边界顶点的川崎/前川边界形式只对纸张平直边上的点校验，折角顶点自动跳过。
